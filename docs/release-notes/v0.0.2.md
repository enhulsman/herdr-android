# v0.0.2 (DRAFT)

Built from commit <sha>.

The first build that connects to your machines and lists their agents. There is
no terminal yet: that comes in a later version.

## New

- **Agents home.** Every agent on your machines in one list, the ones that need
  you first, with what they are asking. Then Done, Working (with a spinner and,
  where the agent reports it, a progress bar) and Idle. Other terminals sit in a
  collapsed group at the bottom. Tap an agent to see its name, machine, state
  and request; opening it marks a finished agent as seen.
- **Machines.** Each machine shows how it is doing: connected, unreachable with
  when it was last connected, waiting for you to unlock the key, herdr-core not
  found, or a herdr-core version that is too old. When a machine drops off, the
  app keeps trying and reconnects by itself; its agents stay listed, marked with
  the time they were last seen.
- **Adding a machine.** Name, host, port and user. On the first connection the
  app shows the machine's host-key fingerprint and connects only after you trust
  it. If that key ever changes, the app refuses to connect and shows both
  fingerprints; you can forget the old key after a confirmation.
- **Your phone's key.** The app makes its SSH key in the phone's secure
  hardware; the key never leaves the phone. Using it needs your fingerprint or
  screen lock, then it stays usable for 30 minutes. If you dismiss the prompt,
  tap Unlock on the Machines screen.
- **The line for your machine.** The Phone key screen shows the one line to add
  to the machine's `~/.ssh/authorized_keys`, with a copy button. That line lets
  the key start herdr-core only: no terminal session, no port forwarding.
  herdr-core can still run commands as you, so treat the key like a login.
- **Export and import.** Save your machine list to a file and load it on
  another phone. Keys and trusted host keys are not in the file: on a new
  phone, add its key line to each machine and trust each host key again.
- **Leaving the app.** About a minute after you leave the app, it closes its
  connections; they open again when you come back.
- **Look.** The dark and light themes of the desktop app (graphite and paper),
  following your phone's dark mode, with their fonts built in.

## After installing

On GrapheneOS, check that the app's Network permission is on (Settings > Apps >
herdr > Permissions). This is the first version that uses the network, and an
update can arrive with it switched off. The Machines screen says "Network
permission is off" when that happens.
