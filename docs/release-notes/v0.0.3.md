# v0.0.3

Built from commit 84ff6e20217a2cd9c99a4eb794ed4378be812b9a.

Fixes from the first test on a real phone. Nothing new to set up.

## Fixed

- **Network permission off.** With GrapheneOS's Network permission off, a
  machine added by host name said its address could not be looked up. Every
  machine now says "Network permission is off", and the app does not try to
  connect until you allow it. Turn it on in Android settings and come back to
  the app: your machines connect at once.
- **A machine that keeps retrying.** While a machine was waiting to try again
  (its key not accepted yet, or unreachable), its card briefly lost its
  explanation and its "Add phone key" row at every attempt. The card now stays
  as it is and reads "retrying" while the attempt runs.

## For your machines

- `scripts/check-restricted-key.sh` now also checks the keys systemd hands to
  sshd (`userdbctl ssh-authorized-keys`, set by default on several
  distributions). Before, it failed on that setting without looking.
