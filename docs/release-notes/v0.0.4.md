# v0.0.4

Built from commit a135dee71c23db84991e792f75d067560ee4077b.

The app icon, and the Network permission fix that v0.0.3 promised.

## New

- **App icon.** herdr's ram on its ivory tile, in the shape your launcher
  uses. With themed icons turned on, it follows your phone's colours.

## Fixed

- **Network permission off, for real this time.** v0.0.3 asked Android
  whether the app may use the network, but GrapheneOS answers "yes" even when
  the Network permission is off. The app now notices that it is refused a
  connection, and every machine says "Network permission is off". Turn it on
  in Android settings and the next attempt connects.
