# v0.1.0

Built from commit 1437a9d886c1cfdf11bf632e3c58a294a00b064f.

The first complete version: live terminals you can type into, and alerts
with the app closed.

## New

- **Live terminal.** Tap an agent to see its terminal as the desk draws it,
  with colours, zoom and scrollback. Opening it switches the terminal to the
  phone's size. Type at the desk and the desk gets its size back while the
  phone keeps watching; exit the terminal's screen on the phone and the desk gets it
  back too.
- **Typing.** The phone keyboard plus two rows of terminal keys (esc, ctrl,
  alt, tab, arrows, ^C and more).
- **Compose.** A sheet for long prompts with autocorrect and dictation. It
  pastes into the agent's input without pressing enter.
- **Between agents.** Swipe on the title bar to move to the next agent that
  needs you, or sideways like tabs.
- **Alerts.** "Needs you" with sound and "Finished" silently, even with the
  app closed. Tap an alert to open that agent's terminal. Each machine card has
  an Alerts row, "Mute alerts" and "Send test alert". After 13 hours without
  word from a machine, a quiet notice says so.

## For your machines

- Alerts need `herdr-push` on each machine and an ntfy server; the release
  includes it, signed. Setup: `docs/herdr-push.md`.
- Newer herdr-core versions now connect without a warning.
