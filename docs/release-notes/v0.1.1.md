# v0.1.1

Built from commit 3d50b796df6db9c5844c39fd7dfb73962a1c7bd8.

Two fixes from using v0.1.0.

## Fixed

- **An agent you quit leaves the list** (#4, fixed in #6). When you quit an
  agent and its terminal is a plain shell again, it moves to "Other terminals"
  instead of staying in the list as Idle, and the title-bar swipe skips it.
- **Coming back with the keyboard up** (#5, fixed in #7). Switching to another
  app and back with the keyboard open no longer pushes the terminal over the
  key rows, stretches the top bar or opens Compose at the top of the screen.

## For your machines

- Updating `herdr-push` is optional: the new one sends no "Finished" alert for
  an agent you quit at the desk within 30 seconds of it finishing (#6).
