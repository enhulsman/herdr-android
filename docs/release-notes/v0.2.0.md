# v0.2.0

Built from commit ebb47268294c0f4001ae8774cc58974285f7814d.

New terminals and agents from the phone.

## New

- **New terminal** (#10). The + on the Agents screen opens a sheet: pick the
  machine and a space, then Terminal, or one of the agents installed on that
  machine (Claude Code, Codex and the others herdr knows). It starts in the
  space's folder as a new tab on your desk, and opens on the phone right away.
  Agents start the way you would start them at the desk, through your shell,
  so your aliases apply; when you quit one, the shell stays. On a machine
  without spaces you pick a folder, and the terminal becomes a new space.

## For your machines

- Update `herdr-push` to get alerts for an agent you started from the phone
  while the desk app is closed (#10).
