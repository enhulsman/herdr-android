# v0.3.0

Built from commit 046e0275d616bca8e53c3fbcfc26fef9192fded4.

Agents go by their session's name, and you can see where they sit.

## New

- **Session names** (#13). An agent is named after the title Claude Code gives
  its session ("Pricing page copy"), not "Claude Code". A name you gave the
  terminal at the desk still comes first; an agent without a title keeps its
  program's name.
- **Where it sits** (#13). The second line in the Agents list and on the
  terminal screen shows the desk's space and tab ("website / 2 · WSL") instead
  of the folder. A terminal the desk has not placed yet still shows its folder.
- **Alerts say which session and where** (#13). "Pricing page copy needs you",
  over "Permission · website / 2 · WSL"; "Pricing page copy finished", over
  "website / 2 · WSL".
- **Private on the lock screen** (#13). If your phone hides sensitive content
  on the lock screen, an alert shows only "An agent needs you · WSL" there.

## For your machines

- Update `herdr-push` to get session names and the space and tab in alerts
  (#13). With the old one, alerts read "Claude Code needs you" as before.
