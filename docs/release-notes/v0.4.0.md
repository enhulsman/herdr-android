# v0.4.0

Built from commit c2225de722ac760fe1cf668162f626ee92ffe2d2.

Read and answer an agent's conversation as a chat, and stay connected in the
background if you want.

## New

- **Chat** (#17). Switch an agent (Claude Code or Codex) between its terminal
  and a chat of its conversation: your messages as bubbles, answers as
  formatted text, tool calls folded into a line you can open, and images you
  can open full screen. A working line shows while the agent works. Answer
  from the message box, photos included; `/` and `!` commands work as in the
  agent's own box. The desk keeps its terminal size while the chat shows.
  When the app can't read an agent's log, you get the terminal, as before.
- **Stay connected** (#16, optional). Keeps the connection open in the
  background, with a quiet notification that counts the agents that need you,
  have finished or are working, so the app opens at once. It costs battery:
  about 22 mA more on our test phone with the screen off (the README has the
  details).
