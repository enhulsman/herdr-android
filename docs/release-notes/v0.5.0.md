# v0.5.0

Built from commit 10ac115a23d05c32f6f46e9d2803e3304833e746.

See what an agent changed, from its terminal or its chat.

## New

- **Changes** (#19). A button in the terminal and chat title bars opens the
  files changed in the agent's folder since the last commit, new files
  included, each with its diff. The list follows the agent while it works, no
  tap needed. A long diff shows its first 2,000 lines and a button for the
  rest; a file too large for the phone says so. Nothing is typed into the
  terminal for it, and back returns to the terminal or chat as you left it.

## Fixed

- The terminal and chat title bars no longer show the agent's state as a
  pill. The screen below already shows it, and the agent's name now has the
  room it needs (#57).
- Opening a chat while the app reconnects to your machine no longer shows
  the terminal with the Chat switch hidden; the chat waits for the machine
  and then shows the conversation (#58).
