# v1.0.0

Built from commit 852cf5a56b2703042e74a9b55eab7c99b4533ac2.

herdr for Android is now kudde, and it is 1.0.

## Moving over

kudde installs as a new app, next to herdr for Android. Import the machine
list you exported from the old app (or add the machines again), then set up
the phone key and alerts once more. On each machine, `herdr-push` becomes
`kudde-push`: [Coming from herdr-push](https://github.com/enhulsman/kudde/blob/main/docs/kudde-push.md#coming-from-herdr-push).
Then remove the old app.

## New

- **kudde** (#75, #77): a new name, written lowercase, and its own icon, an
  ear tag with a prompt on it.
- **TalkBack and large fonts** (#24): TalkBack reads the terminal and new
  chat answers aloud, and each key and Needs you card once. Every screen fits
  the largest font.
- **Less battery** (#48): the animations while an agent works use a third to
  a half of the power they did.
- Setting up from zero needs only the docs (#20, #21), which also say which
  herdr-core versions work (#25).

## Security (#22)

- A multi-line paste into a program that would run each line is refused.
- The chat's second Enter can no longer answer a dialog that opened just
  before it.
- Alerts ignore a push sent again, and every push has the same size.
- Copied chat text is marked sensitive, Recents keeps no picture of
  the app (Android 13 and newer), and a picked photo is read only up to a limit.
- The SSH library is updated for two advisories.

## Fixed

- The Alerts row no longer shows a last push before one came, and a missed
  test alert asks whether kudde-push runs there.
